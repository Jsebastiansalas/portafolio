## 🛠️ Ejecución Local

Para clonar y correr este portafolio en tu máquina local:

```bash
# Clonar el repositorio
git clone https://github.com/Jsebastiansalas/portafolio.git

# Entrar a la carpeta
cd portafolio

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```
